# AutoSub-KZ — Видеоға автоматты қазақша субтитр жасау прототипі

Бұл жоба — пайдаланушы видео сілтемесін (YouTube, т.б.) енгізгенде, жүйе автоматты түрде
дауысты мәтінге түрлендіріп (Speech-to-Text), қажет болса аударып, `.srt` форматында
қазақша субтитр файлын шығаратын веб-қолданбаның MVP (Minimum Viable Product) нұсқасы.

## 1. Жалпы архитектура

```
┌─────────────┐      1) видео URL       ┌──────────────────┐
│   Клиент     │ ───────────────────────▶│   FastAPI сервер  │
│ (веб-браузер)│                         │   (backend)       │
└─────────────┘◀─────────────────────────└────────┬──────────┘
     ▲  5) дайын .srt файл                          │
     │                                               │ 2) видео жүктеу
     │                                               ▼
     │                                     ┌──────────────────┐
     │                                     │  yt-dlp / файл    │
     │                                     │  жүктеу модулі    │
     │                                     └────────┬──────────┘
     │                                               │ 3) аудио бөлу (ffmpeg)
     │                                               ▼
     │                                     ┌──────────────────┐
     │                                     │  Whisper моделі   │
     │                                     │ (Speech-to-Text)  │
     │                                     └────────┬──────────┘
     │                                               │ 4) мәтінді қазақшаға аудару
     │                                               ▼
     │                                     ┌──────────────────┐
     │                                     │ Аударма қызметі   │
     │                                     │ (Translation API) │
     │                                     └────────┬──────────┘
     │                                               │
     │                                               ▼
     │                                     ┌──────────────────┐
     └─────────────────────────────────────│ .srt генераторы   │
                                            └──────────────────┘
```

### Компоненттер сипаттамасы

| # | Компонент | Міндеті | Ұсынылатын технология |
|---|-----------|---------|------------------------|
| 1 | **API қабаты** | Сұраныстарды қабылдау, статусты қайтару | FastAPI + Uvicorn |
| 2 | **Video Downloader** | Видео сілтемесінен файлды жүктеу | `yt-dlp` |
| 3 | **Audio Extractor** | Видеодан аудио дорожканы бөліп алу | `ffmpeg` (арқылы `ffmpeg-python`) |
| 4 | **Speech-to-Text** | Аудионы мәтінге түрлендіру (уақыт белгілерімен) | `openai-whisper` немесе `faster-whisper` |
| 5 | **Translator** | Түпнұсқа тілден қазақ тіліне аудару | Google Cloud Translate API / DeepL / NLLB-200 (ашық үлгі) |
| 6 | **Subtitle Generator** | `.srt` файлын құрастыру | `srt` немесе қолмен жазу |
| 7 | **Task Queue (өндірістік нұсқада)** | Ұзақ есептеулерді фондық режимде орындау | Celery + Redis (MVP-де қажет емес, түсіндірме үшін) |
| 8 | **Storage** | Уақытша видео/аудио/субтитр файлдарын сақтау | Жергілікті диск (MVP), кейін S3/GCS |

### Деректер ағыны (data flow)

1. Пайдаланушы `/process` эндпойнтіне видео URL жібереді.
2. Сервер видеоны жүктеп алады (`yt-dlp`).
3. `ffmpeg` арқылы видеодан тек аудио дорожка бөлініп алынады (`.wav`, 16kHz, моно — Whisper талабы).
4. Whisper моделі аудионы транскрипциялайды және әр сегмент үшін бастау/аяқталу уақытын қайтарады.
5. Егер бастапқы тіл қазақша болмаса, аударма қызметі әр сегментті қазақ тіліне аударады.
6. Нәтиже уақыт белгілерімен бірге стандартты `.srt` форматына жиналады.
7. Дайын файл пайдаланушыға жүктеп алуға қайтарылады.

### Масштабтау бойынша ескертпелер (MVP-ден кейінгі қадамдар)

- Ұзақ видеолар үшін синхронды өңдеу орнына **фондық тапсырма кезегін** (Celery/RQ + Redis) қосу керек, себебі Whisper транскрипциясы бірнеше минутқа созылуы мүмкін.
- Прогрессті бақылау үшін **WebSocket** немесе polling арқылы статус эндпойнтін қосу ұсынылады.
- Дәлдікті арттыру үшін Whisper-дің `large-v3` моделін немесе қазақ тіліне бейімделген fine-tuned модельдерді қарастыруға болады.
- Аударма сапасын жақсарту үшін контекстке негізделген аударма (сөйлемдерді бөлек емес, топтап аудару) қажет.

## 2. Жобаны компьютеріңізде іске қосу (қадам бойынша)

### 2.1. Алдын ала қажетті бағдарламалар

- **Python 3.10+** — [python.org](https://www.python.org/downloads/) сайтынан орнатыңыз
- **ffmpeg** — аудио бөлу үшін міндетті түрде керек:
  - Ubuntu/Debian: `sudo apt install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Windows: [ffmpeg.org](https://ffmpeg.org/download.html) сайтынан жүктеп, PATH-қа қосыңыз

### 2.2. Жобаны орнату

```bash
# 1. Жоба қалтасына өтіңіз
cd kazakh-subtitles

# 2. Виртуалды орта жасаңыз (тәуелділіктерді бөлек ұстау үшін)
python -m venv venv

# 3. Виртуалды ортаны іске қосыңыз
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows

# 4. Барлық қажетті кітапханаларды орнатыңыз
pip install -r requirements.txt
```

> ⚠️ Бірінші рет іске қосқанда Whisper моделі (~150 МБ, `base` өлшемі)
> автоматты түрде жүктеледі — интернет қосылымы қажет, бір реттік ғана.

### 2.3. Серверді іске қосу

```bash
uvicorn app.main:app --reload
```

Терминалда мынадай жол шыққанда сервер дайын:
```
Uvicorn running on http://127.0.0.1:8000
```

### 2.4. Қалай пайдалану керек

**А) Веб-интерфейс арқылы (ең оңай тәсіл):**

Браузерде мына сілтемені ашыңыз:

```
http://127.0.0.1:8000/app
```

1. Видео сілтемесін (YouTube т.б.) өріске қойыңыз
2. Бастапқы тілді таңдаңыз (білмесеңіз — "Автоанықтау" қалдырыңыз)
3. Дәлдік деңгейін таңдаңыз ("Орташа" әдепкі, жылдам әрі жеткілікті сапалы)
4. **"Субтитр жасау"** батырмасын басыңыз
5. Өңдеу аяқталғанда **".srt файлын жүктеп алу"** сілтемесі шығады — соны басып,
   субтитр файлын компьютеріңізге сақтаңыз

**Ә) Swagger құжаттамасы арқылы (API-ды тексеру үшін):**

```
http://127.0.0.1:8000/docs
```

**Б) Терминал арқылы (curl):**

```bash
curl -X POST "http://127.0.0.1:8000/process" \
  -H "Content-Type: application/json" \
  -d '{"video_url": "https://www.youtube.com/watch?v=XXXXXXX", "source_language": "en"}'
```

Жауапта `task_id` және `srt_download_url` қайтарылады. Файлды жүктеп алу үшін:

```bash
curl -O "http://127.0.0.1:8000/download/<task_id>"
```

### 2.5. Дайын .srt файлын видеоға қалай қосу керек

Жүктеп алған `subtitles_kk.srt` файлын кез келген видео плеерге (VLC, т.б.)
"Subtitle → Add subtitle file" арқылы қосуға болады, немесе `ffmpeg` арқылы
видеоға тұрақты (hardcode) етіп енгізуге болады:

```bash
ffmpeg -i original_video.mp4 -vf subtitles=subtitles_kk.srt output_with_subs.mp4
```


## 5. Белгілі шектеулер (келесі қадамдар)

- **Аударма қызметі** қазір тегін, API кілтсіз Google Translate веб-соңғы нүктесін
  қолданады (`deep-translator` арқылы). Бұл нақты жұмыс істейді, бірақ өте көп
  сұраныста (мыс., минутына жүздеген видео) уақытша шектелуі мүмкін. Ауыр
  жүктемеге арналған өндірістік жүйе үшін ақылы Google Cloud Translate API немесе
  DeepL-ге көшу керек (`translator.py`-де қалай көшу керектігі жазылған).
- **Синхронды өңдеу**: сервер видеоны толық өңдегенше клиент күтеді. Ұзақ
  видеоларда (10+ минут) бұл бірнеше минутқа созылуы мүмкін. Өндірістік нұсқа
  үшін Celery/RQ + Redis арқылы фондық тапсырма кезегін қосу ұсынылады.
- **Whisper дәлдігі**: `base` моделі жылдам, бірақ ауызекі сөйлеу/шу көп
  видеоларда қателер жіберуі мүмкін. Дәлдік маңызды болса `medium` немесе
  `large-v3` таңдаңыз (өңдеу уақыты ұзарады).
